# Dispatch documentation

Dispatch documentation is organized by the question you arrived with. The files stay
flat so every answer is one hop from this index; decision records and qualification
receipts remain nested because each is an independently navigated collection.

## Start here

- New to Dispatch? Complete [your first isolated session](getting-started.md).
- Working as an agent? [Inspect prior session history](agent-workflows.md) before
  repeating repository work.
- Using retained terminals on Windows? Follow the
  [Windows agent-session guide](windows-agent-sessions.md).
